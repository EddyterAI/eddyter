# Eddyter Documentation

Integration guides for the Eddyter AI rich text editor SDK. Get an API key at [eddyter.com/user/license-key](https://eddyter.com/user/license-key).

- [React & Next.js](react.md): `eddyter` package, Next.js App and Pages Router, Vite
- [Vue](vue.md): `@eddyter/vue`
- [Svelte](svelte.md): `@eddyter/svelte`
- [Angular](angular.md): `@eddyter/angular`
- [Vanilla JS](vanilla-js.md): `@eddyter/core`, no framework
- [React Native](react-native.md): `@eddyter/react-native`, including Expo
- [Laravel](laravel.md): `eddyter/laravel` (Composer), Blade component, no Node.js required
- [API reference](reference.md): full props and API reference for every framework
